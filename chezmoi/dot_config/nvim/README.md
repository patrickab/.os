# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Markdown

List text is yellow, including nested items and continuation paragraphs.
Bullet markers stay literal Markdown. Inline formatting keeps its own highlights.

## Cursor movement

Cursor and scroll animations are disabled to avoid cursor markers beyond line endings.
Window resize, open, and close animations remain enabled.
